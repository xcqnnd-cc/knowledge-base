# 🎨 AI 绘画 Prompt：人物拆分描述法

很多人刚开始用 AI 生成人物图时，脑子里明明有画面，写出来却只有一句：

> ❌ **错误示范：** 一个很美的女生，高级一点，有氛围感。

问题不在于这句话“错”，而在于它对 AI 来说，**信息量太少、方向太模糊、可执行性太低**。

AI 知道“美”是正向描述，但它不知道你说的“美”到底是：
*   🌸 温柔清新的美
*   ❄️ 清冷疏离的美
*   🔥 明艳张扬的美
*   🏮 东方古典的美
*   📸 杂志大片式的高级美
*   ✨ 动漫角色那种理想化的美

所以，真正有效的 Prompt，不是单纯堆形容词，而是要学会一件事：

> **💡 核心方法：把人物拆开描述。**

你可以把它理解成：把一个模糊的“美女”概念，拆成多个可以控制的视觉变量，再像搭积木一样组合成清晰的 Prompt。

---

## ❌ 一、为什么很多人物 Prompt 没有效果？

新手写人物 Prompt，通常会踩三个坑：

| 避坑指南 | 问题表现 | 核心原因 |
| :--- | :--- | :--- |
| **坑 1：只写结果，不写构成** | `一个很美的女生，很高级，很有氛围感。` | 像审美结论，不像生成指令。没告诉 AI 长相、穿搭、环境和光线。 |
| **坑 2：只写人物，不写画面** | `年轻女性，长发，很漂亮，很温柔。` | 只有“人”，没有“摄影”。画面容易泛、空、平，缺乏场景和光影支撑。 |
| **坑 3：词很多，但主线混乱** | `美女，高级，韩系，日系，古风，杂志风。` | 互相冲突的风格词堆砌，AI 无法判断优先级，导致画面失焦。 |

> **🌟 破局关键：结构清晰，主次明确，变量可控。**

---

## 🧩 二、什么是“人物拆分描述法”？

所谓人物拆分描述法，本质上就是：
> **把“一个人物形象”拆成若干核心维度，让 Prompt 从抽象评价变成具体指令。**

做女性人物图，通常按这几个维度写就够了：

| 拆分维度 | 包含元素 |
| :--- | :--- |
| 👤 **人物本身** | 年龄感、脸型、五官、发型、肤感、气质 |
| 🎨 **风格方向** | 写实、电影感、日系、韩系、国风、动漫、时尚大片 |
| 👗 **服装妆造** | 服饰、配饰、妆容、发色 |
| 🎞️ **镜头语言** | 近景 / 半身 / 全身，正面 / 侧脸，特写 |
| 💡 **光线环境** | 自然光、逆光、窗边光、夜景霓虹、摄影棚柔光 |
| ✨ **画面质感** | 高级、干净、通透、胶片感、细腻、梦幻 |
| 🖼️ **背景场景** | 街头、花海、室内、博物馆、古建筑、海边、咖啡店 |

**📝 万能公式与示例：**

> **公式：主体 + 外貌细节 + 气质 + 服装妆造 + 场景 + 光线 + 镜头 + 风格 + 画质要求**

> **示例：** 一位年轻女性，五官精致，鹅蛋脸，清透白皙的皮肤，长发微卷，眼神温柔干净，带淡淡微笑，穿浅色连衣裙，站在窗边，自然柔光洒在脸上，半身近景，背景虚化，整体氛围清新高级，写实摄影风格，画面细腻，电影感，高级人像摄影。

## ⚙️ 三、从 Prompt 工程看，人物图到底在控制什么？

很多人把 Prompt 当成“灵感作文”，其实从生成逻辑上看，它更像一组**输入变量**。

```text
💡 Prompt 工程公式：
Prompt = 主体设定 + 风格设定 + 画面设定 + 约束条件
```
细化到人物图就是：
```text
人物图 Prompt = 人物本身 + 妆造服饰 + 场景背景 + 光线镜头 + 风格标签 + 质量要求 + 限制条件
```

人物拆分描述法本质上是在做一件更工程化的事：**把模糊审美，拆成可控变量。** 这样写出来的 Prompt，稳定性会更高，结果也更容易收敛。

---

## 🎛️ 四、人物图的 4 层核心控制变量

| 变量层级 | 作用说明 | 包含要素示例 |
| :--- | :--- | :--- |
| **1️⃣ 主体变量** | 决定画面里是**谁** | 年龄感、脸型、五官特征、发型发色、皮肤质感、表情、气质<br/>*(例：年轻女性，鹅蛋脸，黑色微卷长发，气质温柔)* |
| **2️⃣ 风格变量** | 决定这张图**像什么作品** | 写实摄影、韩系写真、国风古典、动漫插画、时尚大片<br/>*(例：韩系清透写真风，注意风格要聚焦)* |
| **3️⃣ 画面变量** | 决定**怎么拍、在哪里拍** | 镜头、视角、光线、场景、背景<br/>*(例：半身近景，窗边自然柔光，背景虚化)* |
| **4️⃣ 约束变量** | 设定边界，**防止跑偏** | 保留原特征、不要过度磨皮、不要网红脸、适合做头像<br/>*(常用于图生图，它的作用是设定边界而不是增加内容)* |

## 🔍 五、人物本身怎么拆？

### 1. ⏳ 年龄感与状态
年龄感不一定要写具体年龄，更常用的是写人物状态：
*   少女感 / 年轻女性 / 轻熟感 / 成熟优雅 / 都市知性女性

### 2. 🎭 脸型和轮廓
*   **偏柔和（温柔/清新）：** 鹅蛋脸、小圆脸、面部轮廓柔和
*   **偏立体（高级/冷感）：** 瓜子脸、下颌线清晰、面部立体

### 3. 👀 五官细节 (抓 2-4 个重点即可)
*   五官精致 / 鼻梁精致 / 眼睛清澈有神 / 杏眼 / 唇形饱满自然 / 耐看型长相

### 4. 🧴 皮肤和肤感
*   **写实风：** 自然健康肤色、真实皮肤纹理、有质感
*   **韩系风：** 肤色白皙通透、奶油肌、清透裸感肌肤
*   **大片风：** 真实皮肤纹理，避免假面感

### 5. 💇‍♀️ 发型 (带状态描述更好)
*   长发自然垂落 / 发丝轻盈蓬松 / 发尾微卷，更显温柔 / 黑发如瀑

### 6. 🌟 气质 (决定整体方向的灵魂)
> 很多时候，你真正想表达的不是“她好看”，而是“她给人的感觉”。

*   **清纯系：** 温柔、甜美、纯净、仙气、少女感
*   **高冷系：** 清冷、知性、高级感、神秘、英气
*   **成熟系：** 明艳、优雅、成熟性感、轻熟感、贵气感

| 风格分类 | 常用关键词 | 适用场景 |
| :--- | :--- | :--- |

| 🌸 **韩系/日系** | 韩系清透妆感、日系氧气感少女、柔和奶油色调、治愈系、自然伪素颜 | 清新头像、日常写真、壁纸 |
| 🏮 **国风/古风** | 国风美人、古典东方气质、汉服写真、水墨意境、发簪/步摇 | 国风写真、节日主题 |

| 👠 **时尚大片感** | 高定时装感、冷调时尚大片、极简高级风、时尚杂志内页 | 杂志海报、品牌视觉 |

## 👗 七、服装妆造与 📷 镜头光线

### 1. 服装妆造：人物设定的第二语言
*   **服装定调：** 连衣裙 (温柔)、西装 (知性)、汉服 (古典)、礼服 (华丽)
*   **配饰点缀：** 珍珠耳饰、玉簪、细框眼镜
*   **妆容质感：** 裸感淡妆、清透妆感、红唇妆面、高级感轻妆

### 2. 镜头语言：你想让观众先看什么
*   **近景/特写：** 强调五官、妆容、情绪
*   **半身：** 最稳妥，表现神态+部分环境
*   **全身：** 表现穿搭、姿态、空间关系

### 3. 光线环境：氛围感真正的来源
> 氛围感主要来自光线，而不是滤镜。

*   **窗边柔光：** 温柔、安静、干净
*   **黄昏暖光：** 浪漫、治愈、柔和
*   **霓虹夜景光：** 都市、时尚、情绪感
*   **冷调光影/摄影棚柔光：** 克制、疏离、高级、专业

### 4. 背景场景与画面质感
*   **场景要匹配风格：** (韩系-窗边/白墙)、(国风-庭院/木窗)、(都市-玻璃幕墙/夜景)
*   **拆解“高级感”：** 干净、通透、克制、细腻、电影感、色彩统一、构图简洁

## 📝 八、一个真正实用的编写流程 (5步法)

写人物 Prompt，不要一上来就硬写整段，按这 5 步走：

1.  **👤 先定“人物是谁”：** 年轻女性 / 东方古典女性
2.  **👀 再定“她长什么样”：** 鹅蛋脸 / 黑色微卷长发 / 肤色通透
3.  **👗 再定“她穿什么、在哪里”：** 穿白色连衣裙 / 位于窗边室内
4.  **📷 再定“怎么拍”：** 半身近景 / 柔和自然光 / 背景虚化
5.  **✨ 最后补风格和限制：** 韩系清新写真风 / 不要过度磨皮

## 🎓 十、结语：学会写“画面”

你以后写 Prompt，不要只写：**“一个很美的女生”**
而要训练自己写成：**“五官精致、皮肤通透、气质温柔、长发微卷、自然淡妆、窗边柔光、半身近景、韩系清新写真风”**

*   前者是**模糊印象**
*   后者是**明确指令**

AI 绘画真正吃的，从来都不是空泛审美，而是可执行描述。
> **💡 不要只描述“她美不美”，要描述“她是怎样美的”。** 
> 这就是人物拆分描述法最核心的价值。
